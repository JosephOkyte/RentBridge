# RentBridge

> *"Bridging the gap between landlords and tenants"*

**RentBridge** is a direct real estate marketplace engineered for the Nigerian rental market. Designed to eradicate the "Agent Pandemic", RentBridge directly connects vetted prospective tenants with verified property custodians—**Landlords**, resident **Caretakers**, and retained **Legal Custodians (Lawyers)**—completely eliminating street agents, illegal inspection fees, and arbitrary 10% agency markups.

---

## 🌟 Key Features

* **Zero Agent Wahala (0% Middleman Commission):** Rent directly from verified title holders with zero agent fees.
* **₦0 Free Property Inspection Guaranteed:** Strict prohibition on viewing fees; prospective tenants never pay transport or registration fees to inspect vacancies.
* **Strict Title & Deed Verification:** Every lister submits proof of ownership (C of O, Governor's Consent, Registered Deed, NBA Supreme Court enrollment for lawyers, or notarized power of custody for caretakers).
* **Interactive Map Discovery:** Pinpointed vacancies across Nigeria's 4 major economic hubs: **Lagos, Abuja, Port Harcourt, and Enugu**.
* **Comprehensive Photo Transparency Standard:**
  * Minimum **12 photos** for residential properties.
  * Minimum **17 photos** for commercial & industrial properties.
  * Mandatory coverage: Street location, full length of access road, compound gates/entrances, and full interior walkthrough.
* **Standard Annual Rent:** Clear, upfront annual lease terms with transparent caution deposits and service charges.
* **Agent Fee Savings Calculator:** Interactive cost calculator illustrating instant tenant savings.
* **Mobile-First Experience:** Native thumb-swipe slideshow gestures, quick-scroll navigation strips, and responsive touch controls.

## 🚀 Getting Started

### Prerequisites
* Node.js (v18+)
* npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/JosephOkyte/RentBridge.git
   cd RentBridge
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
